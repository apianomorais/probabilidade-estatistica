1. ONDE PUBLICAR
-----------------------------------------------------------------
O site e estatico (so HTML, CSS e JavaScript), entao roda em
qualquer hospedagem. Duas opcoes:

--- OPCAO A: GITHUB PAGES (gratuito, recomendado) ---------------

A pasta ja vem preparada como repositorio Git, com o primeiro
commit feito. Falta so enviar.

1. Crie um repositorio PUBLICO e VAZIO no GitHub
   (sem README, sem .gitignore, sem licenca)
2. Nesta pasta, rode os comandos que o GitHub mostra na tela:

       git remote add origin https://github.com/USUARIO/REPO.git
       git push -u origin main

3. No repositorio: Settings > Pages
   Source: "Deploy from a branch"
   Branch: main        Pasta: / (root)
4. Aguarde 1 a 2 minutos. O endereco aparece na propria tela,
   no formato https://USUARIO.github.io/REPO/

Para atualizar o site depois de editar qualquer arquivo:

       git add -A
       git commit -m "descricao da mudanca"
       git push

Vantagens: gratuito, historico de versoes, e os alunos podem
abrir "issues" apontando erros no material.

--- OPCAO B: GODADDY (ou outra hospedagem tradicional) ----------

Envie TODO o conteudo desta pasta para a pasta publica do seu
dominio, normalmente chamada public_html/.

(a) Gerenciador de Arquivos do cPanel
    - cPanel > Gerenciador de Arquivos > public_html
    - "Carregar" e envie o site-probabilidade.zip
    - Botao direito no zip > Extrair; apague o zip depois

(b) FTP (FileZilla ou similar)
    - Host, usuario e senha no painel do GoDaddy, em
      "Hospedagem > Gerenciar > FTP"
    - Arraste index.html, as paginas aulaXX.html, formulario.html
      e a pasta assets/ inteira para public_html/

A pagina inicial e o index.html — nao renomeie esse arquivo.
Como todos os links sao relativos, o site funciona tambem em um
subdiretorio (ex.: .../probabilidade/).

-----------------------------------------------------------------
4. OBSERVACOES TECNICAS
-----------------------------------------------------------------
- Site totalmente estatico: nao precisa de PHP, banco de dados nem
  qualquer configuracao no servidor.
- As formulas sao renderizadas pelo MathJax, carregado do CDN
  jsdelivr. O computador do aluno precisa de internet (o que ja e
  o caso, para acessar o site).
- Os simuladores rodam no navegador do aluno, em JavaScript puro,
  sem bibliotecas externas. Funcionam em celular.
- Cada pagina tem folha de estilo de impressao: ao imprimir ou
  salvar em PDF, menu e botoes somem e as solucoes dos exercicios
  aparecem abertas. Util para gerar apostilas.
- Para adicionar um simulador em qualquer lugar do texto, basta
  inserir no HTML:
      <div data-widget="NOME"></div>
  Nomes disponiveis: dados2, eventos, encontro, contagem, bayes,
  discreta, binomial, poisson, normal, tcl, passeio, moeda,
  exponencial.
